# Changelog

All notable changes to the root Gojent module are documented here. Optional
modules (`providers/*`, `stores/*`, `codjent`, and `examples/google`) are
versioned independently; their release notes belong with their own tags.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Until v1, minor releases may include breaking changes; call them out explicitly.

## [Unreleased]

Changes land here until a release. When cutting a version, move the entries
under a new `## [x.y.z] - YYYY-MM-DD` heading.

## [0.1.0] - 2026-10-30

### Added

- Initial public release of the root module: the agent runtime, canonical LLM
  contracts, typed tools, the session store contract, ready-made tools, and the
  deterministic mock provider.
